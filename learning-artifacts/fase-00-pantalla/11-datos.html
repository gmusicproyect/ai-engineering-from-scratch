Gestión de datos

Los datos son el combustible. Cómo los guardas decide la velocidad.

El problema

Todo proyecto de IA empieza por encontrar datos, bajarlos, cambiarles el formato, separarlos en entrenamiento y evaluación, y versionarlos para que el experimento se pueda repetir. Hacerlo a mano cada vez se rompe.

La idea

La librería datasets de Hugging Face es el camino habitual. Descarga, guarda una caché, convierte formatos y puede transmitir el conjunto sin bajarlo entero.

  1. El Hub de Hugging Face tiene el conjunto.
  2. datasets lo carga o lo transmite.
  3. La caché queda en ~/.cache/huggingface/.
  4. Se convierte entre CSV, JSON, Parquet y Arrow.
  5. Se parte en train, validación y prueba.
  6. Eso entra al entrenamiento.
uv pip install datasets huggingface_hub
from datasets import load_dataset
datos = load_dataset("stanfordnlp/imdb")
print(datos)
print(datos["train"][0])

Parquet y Arrow se leen por columnas y ocupan menos que un CSV grande. Un reparto fijo, con semilla, hace que dos corridas miren las mismas filas.
