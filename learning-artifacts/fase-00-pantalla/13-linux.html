Linux para IA

Casi todo el entrenamiento de IA corre en Linux. Hay que saber lo justo para no quedarse atascado.

El problema

Aunque trabajes en macOS, el servidor con GPU suele ser Linux. Los caminos, los permisos, los paquetes y los procesos no se parecen del todo a los de esta Mac.

Dónde vive cada cosa

RutaQué hay
/homeTu carpeta y los datos del proyecto
/etcConfiguración del sistema
/var/logRegistros
/tmpArchivos que se pueden borrar

Permisos

En -rwxr-xr-- los tres primeros signos son del dueño (leer, escribir, ejecutar), los tres siguientes del grupo y los dos últimos del resto. chmod +x train.py lo hace ejecutable.

Procesos, disco y tmux

df -h
du -sh ~/.cache
sudo apt update && sudo apt install -y git curl wget unzip

tmux mantiene el entrenamiento vivo después de cerrar SSH. Ctrl+B y luego D suelta la sesión. En Windows, el camino del curso es WSL2 con Ubuntu, no el símbolo del sistema.

Al pasar de macOS a Linux cambian detalles: no existe brew por defecto, los paquetes salen de apt, y las GPU de NVIDIA se miran con nvidia-smi.
