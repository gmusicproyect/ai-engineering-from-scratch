El editor

El editor es el copiloto. Se configura una vez para que deje de estorbar.

El problema

Vas a pasar miles de horas escribiendo Python, corriendo cuadernos, depurando bucles de entrenamiento y entrando por SSH a máquinas con GPU. Sin autocompletado, sin tipos y sin formato, cada sesión paga ese roce.

Cinco piezas

  1. El editor base. El curso recomienda VS Code: gratis, en todos los sistemas, con cuadernos.
  2. Extensiones: Python, Pylance, Jupyter, GitLens, Remote SSH y el depurador.
  3. Ajustes de IA: formato automático, revisión de tipos, y una regla cerca de la columna 88.
  4. La terminal integrada, para correr scripts y mirar la GPU.
  5. Desarrollo remoto, para entrar por SSH a una máquina con GPU.
code --version
code --install-extension ms-python.python
code --install-extension ms-python.vscode-pylance
code --install-extension ms-toolsai.jupyter
code --install-extension eamodio.gitlens
code --install-extension ms-vscode-remote.remote-ssh

En macOS, si code no aparece, en VS Code se abre la paleta de comandos con Cmd+Mayús+P y se elige Install 'code' command in PATH.

Cursor, el editor en el que estás ahora, ya cubre la edición con agente. El flujo del curso sigue siendo el mismo: el código vive en el repositorio, la terminal corre las lecciones, y el entorno es .venv.
